# 3D Air Architect Pro

> 손동작만으로 허공에 3D 공간을 설계하는 컴퓨터 비전 기반 인터랙티브 드로잉 시스템

## 📌 프로젝트 소개

3D Air Architect Pro는 웹캠과 컴퓨터 비전 기술을 활용하여 사용자가 실제 도구 없이 공중에 3D 선을 그리고, 회전하고, 수정할 수 있는 인터랙티브 그래픽 애플리케이션입니다.

MediaPipe의 실시간 손 랜드마크 추적과 OpenCV 기반 렌더링 기술을 결합하여 손 제스처만으로 가상의 3차원 공간에서 자유롭게 설계할 수 있습니다.

사용자는 마우스, 키보드, 터치스크린 없이 오직 손동작만으로 3D 오브젝트를 생성하고 수정할 수 있으며, 직관적인 제스처 인터페이스를 통해 새로운 형태의 공간 디자인 경험을 제공합니다.

---

# 🚀 주요 기능

### ✏️ 3D 공중 드로잉

엄지와 검지를 맞대는 Pinch 제스처를 통해 허공에 3D 선을 생성합니다.

* 실시간 3D 좌표 계산
* 부드러운 선 보간(Smoothing)
* 자연스러운 곡선 표현
* 깊이감이 적용된 3D 렌더링

---

### 🖐️ 손동작 기반 인터랙션

모든 기능을 손동작만으로 제어할 수 있습니다.

| 제스처         | 기능       |
| ----------- | -------- |
| 엄지 + 검지     | 3D 선 그리기 |
| 주먹          | 3D 공간 회전 |
| 새끼손가락만 펼침   | 부분 삭제    |
| 엄지 + 중지 더블탭 | 색상 변경    |
| 엄지 + 약지     | 스타일 변경   |
| 주먹 + 슬라이더   | 선 굵기 조절  |

---

### 🎨 다양한 스타일 지원

* SOLID Style
* NEON Style
* DOTTED Style

실시간으로 스타일을 변경하며 다양한 표현이 가능합니다.

---

### 🧹 스마트 부분 삭제

새끼손가락 제스처를 사용하여 원하는 구간만 선택적으로 삭제할 수 있습니다.

전체 초기화가 아닌 부분 수정이 가능하여 실제 드로잉 툴과 유사한 작업 환경을 제공합니다.

---

### 🌍 3D 공간 탐색

주먹 제스처를 사용하여 공간을 회전할 수 있습니다.

* X축 회전
* Y축 회전
* 시점 변경
* 다양한 각도 확인

# 📈 핵심 구현 포인트

### 실시간 손 추적

21개의 손 랜드마크를 분석하여 손가락 상태를 판단합니다.

### 히스테리시스(Hysteresis) 회로 적용

Pinch 상태의 떨림 현상을 최소화하여 선이 끊기지 않도록 구현하였습니다.

### 3D 투영 알고리즘

Perspective Projection을 이용하여 깊이감을 표현하였습니다.

### 부드러운 좌표 보간

손 떨림을 줄여 자연스러운 드로잉 경험을 제공합니다.

### 부분 삭제 알고리즘

삭제 영역과 선분의 충돌을 계산하여 필요한 구간만 제거합니다.
